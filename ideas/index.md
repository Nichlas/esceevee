Inspired by "[Ideas for Computing](https://news.ycombinator.com/item?id=6078335)" this is where I jot down my ideas. Some ideas are more fleshed out and will get their own pages.

1. Family Foto Host/Self-Host
  - Simple control of users
  - Easy user creation
  - Simple control of groups/families
  - Contains Albums/Galleries that can be share to groups or users
  - Payment can be shared/collected within families/groups
  - Each album includes and archive, pictures above a certain number should be in the archive, and only the 10, 20, 30 (user settable) important pictures should be shown in the "front" gallery.
  - Titles, captions, dates should be easily visible when showing picturs, as well as a list of people in the picture.
  - The persons age in the picture should be shown.
  - Persons in the picture get their own page to add facts, including fun facts that can be randomly shown.
  - Errors in metadata should be reported to the album manager/"custodian".
  - Pictures should be easy to exchange for new edited versions.

2. New file format for table data, that supports:
  - version control
  - contain explanations on dataframes and columns
  - contain information about source of data
